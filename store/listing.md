## Description — English

Linkwash removes tracking parameters from every link you open, before the page even loads. Shared links, newsletters, ads and search results are full of codes like utm_source, fbclid or gclid that tell companies where you came from. Linkwash washes them out.

WHAT IT REMOVES
• Campaign tags: UTM, Matomo, HubSpot and more
• Ad click IDs: Google (gclid), Meta (fbclid), Microsoft, TikTok, X, LinkedIn, Pinterest and others
• Email trackers: Mailchimp, Marketo, Klaviyo, Eloqua and others
• Analytics IDs: Google Analytics, Webtrekk, Piano and others
• Site rules for Amazon, eBay, AliExpress, Temu, Etsy, Booking.com, Google, YouTube, Instagram, Facebook, X, TikTok, Reddit, LinkedIn, Spotify and more

MORE THAN PARAMETERS
• Skips redirect pages: links wrapped by Google, Facebook, YouTube, Reddit or LinkedIn go straight to the destination
• Blocks click pings that report which link you clicked
• Copy clean links: right-click a link, use the popup button or press Alt+Shift+C
• Built-in link cleaner: paste any link and see what's removed

YOU'RE IN CONTROL
• Turn categories on or off
• Pause Linkwash on a single site with one click
• Add your own parameters
• Affiliate tags are kept by default, so the creators you like still get paid

PRIVATE BY DESIGN
• No login, no account
• No servers, no analytics, no data collection — everything happens in your browser
• Open source

Available in English, German, Turkish, Spanish, French, Italian, Portuguese, Dutch, Polish, Russian, Ukrainian, Arabic, Hindi, Japanese, Korean, Chinese and Indonesian. Light and dark mode.

## Privacy practices tab

- **Single purpose:** Remove tracking parameters from links so websites can't follow where the user came from.
- **declarativeNetRequestWithHostAccess:** Removes tracking parameters from page and frame URLs before the request is sent.
- **Host permissions (<all_urls>):** Tracking parameters appear on links to any website, so the rules must apply to all sites. A content script cleans links when the user clicks or right-clicks them.
- **webRequest:** Read-only. Counts how many parameters were removed for the toolbar counter and the local statistics. No requests are blocked or modified through this API.
- **storage:** Saves settings and local statistics.
- **contextMenus:** "Copy clean link" and "Open clean link in new tab" menu items.
- **offscreen:** Copies a clean link to the clipboard from the context menu and the keyboard shortcut (the service worker can't use the clipboard).
- **clipboardWrite:** Same as above.
- **favicon:** Shows the current site's icon in the popup and in the paused-sites list.
- **Remote code:** No, all code is included in the package.
- **Data usage:** Check none. The extension collects no user data. Certify the three disclosures.
